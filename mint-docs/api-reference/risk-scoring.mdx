narrative: [Stage 07 · Risk Scoring](/flow/07-risk-scoring).

## Run risk scoring

<Warning>
`POST /risk-scoring/run` has been **removed**. Scoring now runs automatically
as part of `POST /ingest/{clientOrgId}` — and now also **auto-promotes** scored
issues into `risks` rows. See [Pipeline API](/api-reference/pipeline). You can
still start it via the generic, non-org-scoped `POST /jobs` (job type
`score_risks`) for debugging. Requires Azure OpenAI to be configured.
</Warning>

Scores the listed issues (or all org issues if `issue_ids` is omitted).

## Get risk assessment

```http
GET /issues/{issueId}/risk-assessment
```

**Auth:** Bearer

Latest scored assessment for an issue.

### Response `200`

```json
{
  "issue_id": "uuid",
  "model_version": "…",
  "created_at": "…",
  "assessment": {
    "likelihood": "Likely",
    "consequence": "Major",
    "velocity": "Fast",
    "risk_type": "Compliance",
    "inherent_risk": "High",
    "overall_control_effectiveness": "Partially Effective",
    "residual_risk": "High",
    "risk_response": "Mitigate",
    "controls": [
      { "control": "Quarterly access review", "effectiveness": "Partially Effective" }
    ]
  }
}
```

`404 not_found` if the issue has no assessment yet.

### Allowed values

| Field | Values |
| --- | --- |
| `likelihood` | Rare · Unlikely · Possible · Likely · Almost Certain |
| `consequence` | Insignificant · Minor · Moderate · Major · Severe |
| `velocity` | Very Slow · Slow · Moderate · Fast · Immediate |
| `effectiveness` | Effective · Partially Effective · Ineffective · Uncontrolled |
| `inherent_risk` / `residual_risk` | Low · Medium · High · Extreme |
| `risk_response` | Accept · Mitigate · Transfer · Avoid |

The matrices that derive `inherent_risk`, `residual_risk`, and `risk_response` are
documented in [Stage 07 · Risk Scoring](/flow/07-risk-scoring#the-scoring-matrices).
