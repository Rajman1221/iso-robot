## List issues

```http
GET /issues?client_org_id={orgId}&include_classification=true&limit=500
```

**Auth:** Bearer · **Returns:** bare JSON array

### Query parameters

| Param | Notes |
| --- | --- |
| `client_org_id` | Scope to the organisation |
| `include_classification` | Embed each issue's classification when `true` |
| `limit` / `offset` | Paging |

### Response `200`

```json
[
  {
    "id": "uuid",
    "title": "Quarterly access review gaps",
    "body": "…",
    "client_org_id": "uuid",
    "issue_scope": "internal",
    "origin": "from_controls",
    "control_ids": ["uuid"],
    "confidence": 0.78,
    "confidence_source": "llm"
  }
]
```

`confidence` is a 0–1 score reported by the LLM when the issue was derived from controls (`confidence_source: "llm"`). When creation used a heuristic fallback, CSV import, or POC seed, `confidence` is `null` and `confidence_source` is `"heuristic"`. Legacy rows without stored fields return both as `null`.

## Get issue by id

```http
GET /issues/{issueId}
```

**Auth:** Bearer

Single issue. Same fields as list items, including `confidence` and `confidence_source`. `404 not_found` if missing.

---

## Get issue classification

```http
GET /issues/{issueId}/classification
```

**Auth:** Bearer

### Response `200`

```json
{
  "issue_id": "uuid",
  "classification": { "labels": [], "pestel": {} },
  "model_version": "…",
  "created_at": "…"
}
```

`404 not_found` if the issue has no classification yet.
