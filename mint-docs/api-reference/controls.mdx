## Start control extraction (global, non-org-scoped, debug only)

```http
POST /controls/extract
```

**Auth:** Bearer · **Job type:** `extract_controls`

Extracts controls from PDFs across **all** organisations (not scoped to a
`client_org_id`). Returns immediately; poll the job and read `/controls` while
it runs. For a real ingest, use `POST /ingest/{clientOrgId}` instead.

### Request

```json
{
  "document_ids": null
}
```

`document_ids` is optional — if omitted, **every** PDF row in the `documents`
table (across all organisations) is processed.

### Response `200`

```json
{
  "id": "uuid",
  "type": "extract_controls",
  "status": "pending",
  "payload": { "document_ids": [] },
  "error": null,
  "created_at": "…",
  "updated_at": "…"
}
```

Poll `GET /jobs/{id}` (see below) until `status` is `completed` or `failed`.

## List controls

```http
GET /controls?client_org_id={orgId}&limit=500
```

**Auth:** Bearer · **Returns:** bare JSON array

### Query parameters

| Param | Required | Notes |
| --- | --- | --- |
| `client_org_id` | yes | Scope to the organisation |
| `document_id` | no | Filter to one document |
| `limit` | no | Page size |
| `offset` | no | Page offset |

### Response `200`

```json
[
  {
    "id": "uuid",
    "document_id": "uuid",
    "client_org_id": "uuid",
    "control_text": "Access to production systems must be reviewed quarterly.",
    "section_ref": "A.9.2.5",
    "framework": "ISO 27001",
    "source_page": 14,
    "created_at": "…"
  }
]
```

<Tip>
Re-run this endpoint during the extract job — the array grows as the worker commits
controls incrementally.
</Tip>

## Poll the extraction job

See [Jobs → Poll job status](/api-reference/jobs#poll-job-status). Repeat
`GET /jobs/{jobId}` until `status` is `completed` or `failed`.
